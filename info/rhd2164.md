# How do we communicate with it?
The RHD2164 head-stage board as sold [here](https://intantech.com/RHD_headstages.html?tabSelect=RHD64ch&yPos=242) uses the chips' [[rhd2164#]]LVDS [[rhd2164#""DDR""|""DDR""]] [[rhd2164#More details on the SPI interface|SPI]] interface, with a [[rhd2164 register map|register map as found here]].


### More details on the SPI interface 
#### LVDS
On the tin, it uses [low-voltage differential signaling](https://en.wikipedia.org/wiki/Low-voltage_differential_signaling) to communicate over a set of 8 conductors, this pinout of which is here

#### ""DDR""
The 2164 chip is not only using [[rhd2164#LVDS|LVDS]] for its SPI, it also isn't technically 1 64 channel chip, its 2 32 channel ones muxed over the 1 SPI connection making a "Double Data Rate" (or DDR) SPI channel.

It starts on the first falling edge of SCLK. This means that each time SCLK has a falling edge, you get info from the first 32 channel stage, and on each rising edge you get info from the second 32 channel stage.

#### It's also Pipelined btw
Because it being [[rhd2164#LVDS|LVDS]] and [[rhd2164#""DDR""|""DDR""]] wasn't already enough, its also pipe-lined, buffered by 2 commands. The way this works with the 2164 chip versus the other 2000 chips is that when you ask it to convert channel 0 for example, the rising edges contain channel 0 from head-stage A, and the falling edges contain channel 32 from head-stage B[^1]
